# Random Number Generator

A simple Random Number Generator built using React.js.

## Live Demo

[View Random Number Generator](https://random-number-generator-five-wine.vercel.app/)

## Features

- Generates a random number between 1 and 100.
- Generates a new number on every button click.
- Displays a placeholder message before generating.
- Updates the UI dynamically.

## Technologies Used

- React.js
- JavaScript
- CSS
- useState Hook

## Learning Objective

Practised React `useState`, event handling, state management, and conditional rendering.
